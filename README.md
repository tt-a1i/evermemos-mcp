# evermemos-mcp

Universal MCP memory layer powered by EverMemOS.

## Current Positioning
- Works with MCP-compatible clients (coding/chat/study scenarios)
- Uses `space_id` as the primary isolation key
- Cloud-only data strategy (no local persistence)

## V1 Tool Set
- `list_spaces`
- `remember`
- `recall`
- `briefing`
- `forget`
