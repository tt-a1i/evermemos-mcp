# MCP 配置片段

[English](README.md) | [简体中文](README.zh-CN.md)

这些片段用于快速接入 `evermemos-mcp`。

## 使用说明

1. 按你的客户端复制对应 JSON
2. 把 `YOUR_KEY` 替换为真实 `EVERMEMOS_API_KEY`
3. 发布版片段默认使用 `uvx evermemos-mcp@latest`；只有本地源码联调时才改用 `from-source.json`

## 文件列表

- `claude-code.json`
- `cursor.json`
- `cline.json`
- `from-source.json`
